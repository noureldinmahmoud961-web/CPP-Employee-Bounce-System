# C++ Employee Bonus System

## Overview

This project is a simple Object-Oriented Programming (OOP) application written in C++.

The program simulates a basic employee bonus system for two different professions:
- Teacher
- Engineer

Each object stores the employee's name and salary, then checks whether the employee is eligible for a bonus based on a predefined condition.

- Object-Oriented Programming (OOP)
- Classes

- Conditional Statements (if / else)
- User Input & Output
- Salary Bonus Calculation
